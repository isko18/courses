# Руководство по работе с видео в админке Django

## Обзор

Админка была обновлена для удобного просмотра и управления загруженными видео файлами.

## Новые возможности

### 1. Список уроков

В списке уроков (`/admin/users/lesson/`) теперь отображается:

- **Колонка "Видео файл"** - показывает:
  - 📹 Ссылку на редактирование урока с размером файла
  - ▶ Кнопку "Просмотр" для открытия видео в новой вкладке

**Пример отображения:**
```
📹 Видео (2.5 GB) | ▶ Просмотр
```

### 2. Фильтр по наличию видео

В правой панели фильтров добавлен фильтр **"Наличие видео файла"**:
- Есть видео файл
- Нет видео файла

### 3. Страница редактирования урока

При редактировании урока (`/admin/users/lesson/{id}/change/`) доступны:

#### Секция "Видео"

1. **Поле "Video file"** - для загрузки/изменения видео файла
2. **Превью видео** - встроенный видео плеер для просмотра
3. **Информация о видео** - показывает:
   - Размер файла (B, KB, MB, GB)
   - Путь к файлу
   - Длительность видео (если доступна)

#### Структура секции "Видео":

```
┌─────────────────────────────────────┐
│ Видео                               │
├─────────────────────────────────────┤
│ Video file: [Выбрать файл...]     │
│                                     │
│ Превью видео:                       │
│ [Видео плеер с контролами]          │
│                                     │
│ Информация о видео:                 │
│ 📁 Информация о файле:              │
│ Размер: 2.5 GB                      │
│ Путь: videos/2025/01/15/video.mp4  │
│ Длительность: 00:15:30              │
│                                     │
│ Video url: [YouTube или внешняя]    │
│ YouTube video id:                  │
│ Youtube status: ready               │
│ Youtube error:                      │
└─────────────────────────────────────┘
```

### 4. Просмотр видео

Админы могут просматривать видео двумя способами:

1. **В админке** - через встроенный видео плеер на странице редактирования
2. **В новой вкладке** - через кнопку "▶ Просмотр" в списке уроков

**Важно:** Для просмотра видео в админке требуется авторизация. Если видео не загружается, убедитесь, что вы авторизованы.

## Права доступа

- **Суперпользователи (is_superuser)** - полный доступ ко всем видео
- **Администраторы (is_staff)** - полный доступ ко всем видео
- **Преподаватели** - доступ только к своим урокам
- **Студенты** - доступ только к открытым урокам по тарифу

## Полезные функции

### Поиск уроков с видео

Используйте фильтр "Наличие видео файла" → "Есть видео файл" для быстрого поиска всех уроков с загруженными видео.

### Проверка размера файла

Размер файла отображается в:
- Списке уроков (в колонке "Видео файл")
- На странице редактирования (в секции "Информация о видео")

### Просмотр видео

1. Откройте урок в админке
2. Прокрутите до секции "Видео"
3. Найдите "Превью видео"
4. Используйте стандартные контролы видео плеера

Или используйте кнопку "▶ Просмотр" в списке уроков для открытия в новой вкладке.

## Примеры использования

### Поиск всех уроков с видео

1. Перейдите в `/admin/users/lesson/`
2. В правой панели выберите фильтр "Наличие видео файла"
3. Выберите "Есть видео файл"
4. Нажмите "Применить"

### Просмотр информации о видео

1. Откройте любой урок из списка
2. Прокрутите до секции "Видео"
3. Найдите блок "Информация о видео"
4. Здесь будет показан размер, путь и длительность

### Замена видео файла

1. Откройте урок для редактирования
2. В секции "Видео" найдите поле "Video file"
3. Нажмите "Выбрать файл" и выберите новое видео
4. Сохраните изменения

**Примечание:** При замене видео файла старый файл будет удален, а новое видео будет обработано (сжатие, оптимизация).

## Технические детали

### Размеры файлов

Размер отображается в удобном формате:
- До 1 KB: в байтах (B)
- До 1 MB: в килобайтах (KB)
- До 1 GB: в мегабайтах (MB)
- От 1 GB: в гигабайтах (GB)

### Форматы видео

Поддерживаются все форматы, которые понимает ffmpeg:
- MP4, AVI, MOV, MKV, WebM и другие

### Хранение

Видео файлы хранятся в:
```
media/videos/YYYY/MM/DD/filename.mp4
```

Где:
- `YYYY` - год
- `MM` - месяц
- `DD` - день
- `filename` - имя файла (автоматически генерируется)

## Устранение неполадок

### Видео не отображается в админке

1. Проверьте, что файл существует на сервере
2. Убедитесь, что вы авторизованы как администратор
3. Проверьте права доступа к файлу
4. Попробуйте открыть видео через кнопку "▶ Просмотр"

### Размер файла не отображается

Это может произойти, если:
- Файл еще загружается
- Файл был удален с сервера
- Проблемы с доступом к файловой системе

В этом случае проверьте файл вручную через файловую систему.

### Видео не воспроизводится

1. Проверьте формат видео (должен поддерживаться браузером)
2. Попробуйте открыть видео в новой вкладке
3. Проверьте консоль браузера на наличие ошибок
4. Убедитесь, что ffmpeg правильно обработал видео

## Дополнительная информация

- Максимальный размер файла: 20 GB
- Автоматическое сжатие: включено по умолчанию
- Поддержка Range requests: да (для перемотки)
- Кэширование: 1 час
